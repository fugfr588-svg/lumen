# Lumen - client-side PvP/QoL mod (Fabric, Minecraft 1.21.11)

Lightweight, modular PvP client mod with a dark translucent Click GUI.
Original design and code; only inspired by the general look of minimal PvP clients.

## Open / build
1. Open this folder in IntelliJ IDEA (File > Open > `build.gradle`). Use JDK 21.
2. If there is no `gradlew`, run `gradle wrapper` once (or let IntelliJ use its bundled Gradle 9.x).
3. Run configuration `Minecraft Client` is generated by Loom. Or `./gradlew build` -> `build/libs/lumen-1.0.0.jar`.

Versions (`gradle.properties`): MC 1.21.11, Yarn 1.21.11+build.4, Fabric API 0.141.1+1.21.11, Loom `net.fabricmc.fabric-loom-remap`.

## Use
* **Right Shift** opens the Click GUI (rebindable in Controls > Lumen).
* Left-click a module = toggle, right-click = settings drawer (sliders, toggles, modes, keybind).
* Drag the panel by its top strip. **HUD Editor** (sidebar) lets you drag HUD elements with edge/centre snapping.
* Client > Interface: accent hue/saturation, background blur, animations on/off.
* Config is saved to `config/lumen.json` when the GUI closes and on game exit.

## Modules
Combat: Target HUD, CPS, Keystrokes, Combo, Reach - HUD: FPS, Ping, Coordinates, Armor, Potions - Movement: Toggle Sprint - Visual: Fullbright (client-side night vision) - Client: Interface.

## Layout
```
dev.lumen
  LumenClient            entrypoint
  config/ConfigManager   JSON persistence
  module/                Module, HudModule, Category, ModuleManager, setting/*, impl/*
  gui/                   ClickGuiScreen, HudEditorScreen, component/* (cards + setting widgets)
  render/                Draw (rounded rects, shadows, text), Theme (accent/palette)
  input/                 InputHandler (GUI key + module keybinds), CpsTracker
  event/                 ClientEvents (all Fabric hooks), HudRenderer
  util/                  Animation, Colors, KeyNames
```
## Add a module
Subclass `Module` (or `HudModule`), add settings with `add(new BooleanSetting(...))`, register in `ModuleManager.init()`. GUI, config and keybind support are automatic.

## Notes
* Written without access to Fabric's Maven, so it has NOT been compiled by me. 1.21.9-1.21.11 changed several GUI APIs;
  if the compiler complains, the most likely spots are `Click`/`KeyInput` usage in the two Screen classes,
  `KeyBinding.Category`, and `Window.getHandle()`. Fixes should be one-liners.
* No mixins are used (zoom, hit-colour, etc. would need them), which keeps the mod robust across patch versions.

## Getting the jar with no installs (GitHub Actions)
1. Make a free GitHub account, create a new repository, upload the contents of this folder (including `.github`).
2. Open the repo's **Actions** tab - the "Build jar" workflow runs automatically (or press *Run workflow*).
3. When it turns green, open the run and download the **lumen-jar** artifact. Unzip it: `lumen-1.0.0.jar` goes in `.minecraft/mods` next to Fabric API.
